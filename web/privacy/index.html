와이파이 렌즈

개인정보 처리방침

시행일: 2026년 10월 6일

와이파이 렌즈(이하 "앱")는 Wi-Fi 안내문을 카메라로 인식해 Wi-Fi 연결을 돕는 앱입니다. 앱은 회원가입, 로그인, 서버가 없으며 개발자는 사용자의 정보를 수집하거나 전송받지 않습니다.

1. 처리하는 정보와 목적

정보목적처리 위치보관
카메라 영상, 사진안내문의 Wi-Fi 이름과 비밀번호 인식기기 안인식 직후 삭제하며 저장하지 않습니다.
갤러리에서 고른 사진위와 같음기기 안인식 직후 사본을 삭제합니다.
Wi-Fi 이름, 비밀번호Wi-Fi 연결 요청, 기록 화면 표시기기 안기록 탭에서 지울 때까지 iOS 키체인 또는 Android Keystore에만 암호화해 저장합니다.

글자 인식은 Google ML Kit의 온디바이스 모델로 기기 안에서 처리하며, 사진과 인식된 글자는 기기 밖으로 전송되지 않습니다.

2. 제3자 제공 및 외부 전송

개발자는 어떤 정보도 제3자에게 제공하지 않습니다. 다만 앱에 포함된 Google ML Kit 라이브러리는 기능 개선을 위해 API 사용량과 성능 같은 진단 정보를 Google에 보낼 수 있습니다. 이 정보에는 사진, 인식된 글자, Wi-Fi 이름이나 비밀번호가 포함되지 않습니다. 자세한 내용은 Google ML Kit 약관을 참고하세요.

3. 권한

  • 카메라: 안내문 촬영에 사용합니다.
  • 사진(갤러리): 사용자가 직접 고른 사진 한 장만 읽습니다.
  • 위치 권한은 요청하지 않습니다.

4. 정보 삭제

  • 기록 탭에서 항목을 밀어서 지우거나 "모두 지우기"를 누르면 저장된 Wi-Fi 이름과 비밀번호가 기기에서 삭제됩니다.
  • Android에서는 앱을 삭제하면 기록도 함께 삭제됩니다.
  • iPhone에서는 앱을 삭제해도 기록이 기기의 키체인에 남을 수 있습니다. 완전히 지우려면 앱을 삭제하기 전에 기록 탭에서 "모두 지우기"를 눌러 주세요.
  • 앱이 요청해 기기에 추가된 Wi-Fi 네트워크는 기기의 설정 앱에서 지울 수 있습니다.
