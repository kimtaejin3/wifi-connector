## 기본 스토어 등록정보

**간단한 설명 (80자)**

```
와이파이 안내문을 카메라로 비추면 이름과 비밀번호를 읽어 바로 연결해요
```

**자세한 설명 (4000자)**

```
긴 Wi-Fi 비밀번호를 한 글자씩 옮겨 치던 번거로움을 없앴습니다.
카페, 식당, 숙소에 붙은 Wi-Fi 안내문을 카메라로 비추면 와이파이 렌즈가 네트워크 이름과 비밀번호를 찾아 바로 연결해 드립니다.

■ 비추기만 하면 끝
안내문을 화면 가운데 영역에 맞추면 셔터를 누르지 않아도 글자를 읽기 시작합니다. 여러 장면을 비교해 가장 정확한 값을 고르기 때문에 흔들려도 잘 읽습니다.

■ 다양한 안내문 형식
"Wi-Fi : 카페모모", "ID / PW", "비밀번호는 abc12345 입니다" 처럼 가게마다 다른 표기를 알아봅니다. 한글과 영문, 특수문자, 대소문자를 그대로 인식합니다.

■ 확인하고 연결
찾은 Wi-Fi 이름과 비밀번호를 보여 드리고, 틀린 글자가 있으면 바로 고칠 수 있습니다. 헷갈리기 쉬운 글자는 다른 후보로 함께 제안합니다.

■ 사진으로도 연결
미리 찍어 둔 안내문 사진을 갤러리에서 골라도 됩니다.

■ 연결한 Wi-Fi는 기록에
연결한 Wi-Fi 이름과 비밀번호가 기록 탭에 남아 언제든 다시 확인할 수 있습니다. 기록은 기기 안에 암호화되어 저장됩니다.

■ 개인정보를 밖으로 보내지 않습니다
글자 인식은 모두 기기 안에서 처리합니다. 회원가입도, 서버도 없고, 사진은 인식 직후 지웁니다. 위치 권한도 요청하지 않습니다.

※ Wi-Fi 연결은 Android가 보여 주는 네트워크 저장 확인을 거쳐 이루어집니다.
※ 브라우저 로그인이 필요한 Wi-Fi는 연결 후 로그인 화면이 따로 나타납니다.
```

## 데이터 보안

- 데이터 수집 또는 공유: **예** (앱에 포함된 Google ML Kit가 진단 정보를 보낼 수 있음)
- 전송 중 암호화: 예
- 삭제 요청 방법: 사용자 데이터는 기기에만 있고 앱에서 직접 지움 (서버 계정 없음)
- 수집 항목: **앱 정보 및 성능 > 비정상 종료 로그, 진단**
  - 수집만 함, 공유 안 함
  - 일시적으로 처리하지 않음 → 아니요
  - 필수 (사용자가 끌 수 없음)
  - 목적: 앱 기능, 분석
- 사진, Wi-Fi 이름과 비밀번호는 기기 밖으로 나가지 않으므로 수집에 해당하지 않음

## 업로드 키

- 키 파일: `~/.android-keys/wifi-lens-upload.jks` (별칭 `upload`)
- 비밀번호: `~/.android-keys/wifi-lens-key.properties`
- 두 파일은 git에 없어요. 따로 안전한 곳에 백업해 두세요. 잃어버리면 Play Console에서 업로드 키 재설정을 요청해야 해요.
- Play 앱 서명을 쓰므로 실제 배포 서명 키는 Google이 보관해요.
